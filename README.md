# GOD VS GOD · ศึกเทพยุโรป

เกมการ์ดภาษาไทยสำหรับผู้เล่นหนึ่งคนกับคู่แข่งคอมพิวเตอร์ 1–3 คน เลือกเทพและอาวุธจากตัวเลือกที่สุ่มให้ แล้วประลองจนเหลือผู้รอดคนสุดท้าย

## เปิดเล่น

ดาวน์โหลดหรือโคลนคลังนี้ แล้วเปิด `index.html` ในเบราว์เซอร์ ไม่ต้องติดตั้งโปรแกรมเสริมหรือเริ่มเซิร์ฟเวอร์

เล่นบนเว็บได้ที่ [GOD VS GOD](https://gvg-divine-arena-kh.leaflesspumpkin512.chatgpt.site/) (เว็บส่วนตัวของเจ้าของโปรเจกต์)

## ในเกม

- เทพยุโรป 30 ตัว อาวุธ 20 ชิ้น และกองการ์ดปกติ 100 ใบ
- มีการจั่วและสลับอาวุธ การสังเวย การตอบโต้ และการ์ดสนามสะสม
- เปิดเมนู **วิธีเล่น** เพื่อดูรายละเอียดและกติกาที่ใช้ในต้นแบบ ความสมดุลยังไม่ได้ทดสอบกับผู้เล่นจริง

## ไฟล์หลัก

- `index.html`, `style.css` และ `app.js` เป็นหน้าเกม
- `engine.js` จัดการเทิร์นและการตัดสินผล
- `data.js` เก็บข้อมูลเทพ อาวุธ และการ์ด
- `assets/` เก็บภาพที่ใช้ในเกม
